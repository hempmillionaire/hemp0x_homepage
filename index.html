about

hemp0x is a proof-of-work blockchain launched fairly at block 0. There is no premine. There was no presale. No tokens were allocated to founders, VCs, or insiders.

Every coin in circulation was mined by independent miners using computational work. The network is decentralized, permissionless, and maintained by its community.

hemp0x follows the principles of early cryptocurrency projects: fair distribution, transparent consensus, and resistance to centralized control.

mining

hemp0x uses the KAWPOW mining algorithm. Mining is open to anyone with GPU hardware and compatible mining software.

Example mining commands:

# Using nbminer
./nbminer -a kawpow -o stratum+tcp://pool.example.com:4444 -u YOUR_WALLET_ADDRESS

# Using t-rex
./t-rex -a kawpow -o stratum+tcp://pool.example.com:4444 -u YOUR_WALLET_ADDRESS

# Solo mining
./hemp0x-cli setgenerate true 4

Join a mining pool or solo mine directly. Block rewards are distributed to miners according to the emission schedule defined in the protocol.

https://147-93-185-184.sslip.io/ Mining pool with zero fees and block finders reward is 20% and 80% gets spread across all miners in pool evenly. You can solo mine as well without split fees, but you will likely get more rewards mining the shared pool.

Community members without a GPU mining capable computer can alternatively use https://miningrigrentals.com to mine with renting a KawPoW rig. All you need is your wallet and the pool info using the mining pool instructions on the pool's site.

Wallets

Hemp0x currently provides three wallet options:

  • CLI Wallet - A command-line wallet for advanced users, operators, and server deployments. The CLI wallet supports full-node operation, transaction creation, and asset management.
  • Hemp0x Commander Wallet - A desktop GUI wallet for Windows, macOS, and Linux. Commander runs a Hemp0x node locally and supports sending and receiving HEMP, creating assets, creating sub-assets, creating restricted assets, and managing chain features through a built-in command interface. Snapshot files are provided to help new installations sync closer to the current chain height faster.
  • WebCom Web/PWA Wallet - A non-custodial browser wallet for desktop and mobile. Users can create or import a wallet directly in the browser, and mobile users can install it as a progressive web app by using the browser's share menu and selecting "Add to Home Screen." WebCom does not run a local node; it connects to Hemp0x Web Services for indexed chain data and transaction broadcasting.

WebCom supports sending and receiving HEMP, wallet backup and recovery, asset viewing and management, intra-chain swaps for Hemp0x assets/HEMP, and cross-chain atomic swap workflows for BTC/HEMP.

Always save your seed phrase and wallet backup securely. Hemp0x wallets are non-custodial: your keys, your crypto.

Source code and related tools are available through the HEMP0X GITHUB repositories.

assets & nfts

hemp0x supports native on-chain assets and NFTs. All asset data is stored directly on the blockchain. No IPFS. No external storage.

Create tokens, issue unique assets, and transfer ownership using the built-in asset layer. Asset creation requires burning a small amount of HEMP. 

# Create an asset
./hemp0x-cli issue "ASSET_NAME" 1000000

# Transfer asset
./hemp0x-cli transfer "ASSET_NAME" 100 RECIPIENT_ADDRESS

# Create unique NFT
./hemp0x-cli issueunique "NFT_NAME" ipfs_hash=false data="on-chain data"
